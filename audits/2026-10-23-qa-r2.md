### QA-021: The public sign-up API now confirms which emails have accounts
- **Area:** API / privacy (side effect of the QA-004 fix)
- **URL:** https://kinetic.openship.org/api/graphql
- **Steps:** Anonymous `mutation { registerMember(data:{email:"<known>",password:"…",name:"QA"}) { id } }`.
- **Expected:** The storefront gets a helpful message, without the open API acting as a lookup for whether an email belongs to a member.
- **Actual:** Returns `"An account with that email already exists"`, `code: ACCOUNT_EXISTS`, to any anonymous caller. The mutation also creates accounts directly over the API with no UI step: a valid call created `qa-probe@example.com` (see Test data). The friendly message is right for the storefront. Rate-limit `registerMember` per IP (`signupError` already maps "too many"), and consider a bot check on direct API sign-ups.
- **Likely file:** `features/keystone/mutations/memberRegistration.ts`, `features/keystone/security/graphql-limits.ts`.
